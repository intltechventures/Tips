
# Testing Tips 


## Simple Local Web Server Testing Options

- **Python http.server**: 
  + If you have Python installed, just open your terminal in your project folder and run: 
    * ```python3 -m http.server```
  + It instantly hosts your files at http://localhost:8000.


- **Node.js http-server**: 
  + If you use Node, run:
    * ```npx http-server```
  + to immediately serve the current directory without a permanent global installation.
